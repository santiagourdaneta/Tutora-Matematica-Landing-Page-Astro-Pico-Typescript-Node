## 🎯 Objetivo del Proyecto

El objetivo principal de este proyecto es demostrar cómo construir una landing page de alta conversión y alto rendimiento utilizando tecnologías modernas y minimalistas. La página se centra en la propuesta de valor única de la tutora: simplificar conceptos complejos de Álgebra Lineal, Cálculo y Programación Lineal.

### Características Clave:

* **Performance:** Optimizado para el **Largest Contentful Paint (LCP)**, con carga asíncrona de fuentes y preloads estratégicos.
* **Seguridad:** Implementación de encabezados de seguridad críticos (HSTS, CSP con Trusted Types) a nivel de `.htaccess`.
* **Responsive & Minimalista:** Diseño limpio y accesible garantizado por el *framework* **Pico.css**.
* **Desarrollo Moderno:** Utiliza el *bundler* de Astro y su arquitectura de *Islands* para JavaScript cero.

---

## ⚙️ Tecnologías Utilizadas

* **Astro 🚀:** Framework de desarrollo web para la arquitectura.
* **Pico.css 🧼:** Minimalista *framework* CSS para estilos limpios y accesibilidad nativa.
* **TypeScript:** Para una tipificación robusta en el *backend* y *frontend*.
* **Node.js / npm:** Entorno de ejecución y gestor de paquetes.

---

## 🛠️ Instalación y Uso

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/santiagourdaneta/Tutora-Matematica-Landing-Page-Astro-Pico-Typescript-Node](https://github.com/santiagourdaneta/Tutora-Matematica-Landing-Page-Astro-Pico-Typescript-Node)
    cd Tutora-Matematica-Landing-Page-Astro-Pico-Typescript-Node
    ```
2.  **Instalar dependencias:**
    ```bash
    npm install
    ```
3.  **Ejecutar en desarrollo:**
    ```bash
    npm run dev
    ```
4.  **Compilar para producción (static build):**
    ```bash
    npm run build
    ```
    *Para testear el rendimiento final, usa `npm run preview`.*
